# yerscan dashboard

A Flask dashboard for viewing JSON reports generated by `yerscan.py`. It includes a report library, risk overview, Chart.js charts, a flattened findings table, client-side filters/sorting/pagination, expandable vulnerability evidence, and filtered CSV export.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

Open `http://127.0.0.1:5000`. The dashboard looks for `*.json` reports in `reports/` by default. A small mixed-risk sample report is included at `reports/sample_report.json`. You can also upload a report from the header.

```bash
YERSCAN_REPORT_DIR=/path/to/reports python3 app.py
```

`parser.py` handles yerscan JSON parsing and flattening without pandas or any database. For a folder path supplied outside the UI, set `YERSCAN_REPORT_DIR` before starting Flask.

Routes:

- `/` — report library, newest first
- `/reports/<report>.json` — report overview and risk charts
- `/reports/<report>.json/findings` — flattened findings table
- `/reports/<report>.json/findings.csv` — server-side full export endpoint
